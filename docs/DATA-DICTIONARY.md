# 岛线清算数据字典

| 段 | 字段 | 约束 |
|---|---|---|
| 清算 | `as_of` | 截至该时点收到的回传参与清算 |
| 档期 `sailings` | `id`、`origin`、`destination`、`open`、`close`、`refund_until`、`departure` | 开办含起点，截止与停退点不含。发船早于或等于清算点即已发船 |
| 席位 `capacities` | `trip`、`tier`、`capacity`、`groups` | 每船每层级一条。通用允许所有资格，专席要求对应资格 |
| 回传 `events` | `id`、`type`、`order`、`trip`、`tier`、`group`、`time`、`received` | 回传时间默认业务时间。退票按接收时间裁决，其余按业务时间回放。同秒按输入行序 |
| 支付、保留、候补 | `payment`、`expires` | 支付码同单同席去重。保留到期先释放再处理同秒回传。匹配的支付可接替自己的有效保留 |
| 换票、退票 | `ticket`、`to_trip`、`to_tier` | 原票号是上次出票回传编号。换票目标满、原票失效或资格不符均保留现状 |

时间须带偏移、精确到秒。输出按 UTC 秒保存，显示上海时间。编号原字符保留，订单号前导零有意义。
每个订单同一时刻只可出票或保留一次。候补入队后按时间及行号尝试该层级开放席位，递补成功即出票。
已截单的开放余位是账面空席。到站临时放行、票款退款和候补支付属于航务外部流程。
输入使用 UTF-8 JSON，可带 BOM。空回传表示尚无订单。无有效船班时请求失败。同一船班或席位层级定义冲突时全部隔离。
